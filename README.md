# برنامج كاشير بسيط (CLI)

برنامج كاشير بسيط يعمل على الكمبيوتر عبر سطر الأوامر باستخدام Python.

## المميزات
- إضافة منتجات (اسم + سعر + كمية).
- عرض سلة المشتريات.
- تطبيق خصم يدوي.
- حساب ضريبة القيمة المضافة (افتراضياً 15%).
- حساب الباقي بعد الدفع.
- حفظ الفاتورة في ملف نصي اختياري.

## التشغيل

```bash
python3 cash_register.py
```

## المتطلبات
- Python 3.10 أو أحدث.
